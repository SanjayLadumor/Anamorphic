# Anamorphic 🎭

An interactive and visually immersive web project inspired by anamorphic design principles and cinematic UI aesthetics. Built to create smooth, engaging visual experiences with modern frontend technologies.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/SanjayLadumor/Anamorphic.git
```

Navigate to the project folder:

```bash
cd Anamorphic
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
